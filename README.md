# 🧾 Makachi Inventory UI

**A modern frontend for inventory management.**  
Makachi Inventory UI is a responsive web interface built with Razor Pages and .NET 8, designed to support the inventory operations of Makachi Global Enterprise. This project focuses on clean UI architecture, intuitive navigation, and scalable component design — all tailored for a seamless inventory management experience.

## 🏢 About the Client

Makachi Global Enterprise is a growing retail and distribution business. This frontend application was developed to provide a user-friendly interface for managing their inventory workflows, including product listings, stock levels, and category organization.

## 🚀 Project Overview

This project delivers a structured and responsive frontend for an inventory system. It includes:

- Dynamic Razor Pages for product and category views
- Form-based interfaces for adding and editing items
- Modular layout with reusable components
- Responsive design for desktop and mobile

> **Note:** This is a frontend-only implementation. Backend services and database integration are assumed to be handled separately or in future development phases.

## 🛠️ Tech Stack

- **Framework:** ASP.NET Core 8 (Razor Pages)
- **Language:** C#
- **UI:** Razor Pages, HTML5, CSS3, Bootstrap 5
- **Routing:** Razor Pages routing conventions
- **Tooling:** Visual Studio 2022+, .NET 8 SDK

## ✨ Features

- 🧾 **Product Listings:** Paginated and filterable product views  
- 📝 **Add/Edit Forms:** Clean forms for product and category management  
- 🗂️ **Category Management:** Organize inventory by categories  
- 📱 **Responsive Layout:** Optimized for mobile and desktop  
- 🧩 **Reusable Components:** Layouts, partials, and shared UI elements
